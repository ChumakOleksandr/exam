# Gesture Slides — керування презентацією жестами

Застосунок отримує відео з камери, визначає точки правої руки через MediaPipe
і показує слайди у вікні OpenCV. Підтримує навігацію, кольорові лінії та гумку.

## Встановлення на Windows

Потрібні **64-бітний Python 3.10, 3.11 або 3.12**, вебкамера і графічний робочий стіл.
Команди нижче виконуються в PowerShell або терміналі PyCharm.

```powershell
git clone https://github.com/ChumakOleksandr/exam.git
cd exam
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Якщо проєкт уже є на комп'ютері, перейдіть у його папку замість повторного
клонування. Якщо вже маєте робоче оточення, достатньо повторити встановлення
залежностей: після рефакторингу додано **PyYAML**.

У PyCharm виберіть **Settings → Project → Python Interpreter → Add Interpreter →
Existing environment** та файл `.venv\Scripts\python.exe` із папки проєкту.
Моделі Hands входять до пакета MediaPipe; окремий файл моделі не потрібний.
Версія MediaPipe зафіксована, оскільки проєкт використовує `mp.solutions.hands`.

## Запуск

```powershell
.\.venv\Scripts\python.exe main.py
```

Покажіть відкриту праву долоню й утримуйте понад секунду. Для виходу натисніть
**Esc** або **q** у вікні OpenCV, або закрийте одне з вікон.
Зміни YAML застосовуються після перезапуску програми.

За замовчуванням слайди читаються з папки `slides` поруч із `config.yaml`.
Для копії проєкту в `A:\exam` це **`A:\exam\slides`**. Зображення PNG/JPG/JPEG
сортуються природно: `slide2.png` перед `slide10.png`.
Відсутні початкові матеріали можна завантажити окремо (потрібен інтернет):

```powershell
.\.venv\Scripts\python.exe download_assets.py
```

## Параметри argparse

```powershell
.\.venv\Scripts\python.exe main.py --help
.\.venv\Scripts\python.exe main.py --camera 1
.\.venv\Scripts\python.exe main.py --slides "A:\exam\slides"
.\.venv\Scripts\python.exe main.py --swap-hands
.\.venv\Scripts\python.exe main.py --config "custom.yaml"
```

| Параметр | Значення |
|---|---|
| `--config PATH` | Повний YAML-файл; типово `config.yaml` поруч із `config.py` |
| `--camera N` | Індекс камери; перевизначає `camera.index` із YAML |
| `--slides PATH` | Папка слайдів; перевизначає `paths.slides` |
| `--swap-hands` | Поміняти місцями очікувані мітки Left/Right, якщо камера вже віддзеркалює кадр |
| `--no-swap-hands` | Явно вимкнути перестановку міток, навіть якщо вона ввімкнена в YAML |
| `-h`, `--help` | Показати довідку та завершити роботу |

Явні CLI-параметри мають пріоритет над YAML. Відносні шляхи CLI рахуються від
поточної робочої папки термінала, а `paths.slides` у YAML — від папки YAML.
Для `download_assets.py` доступні `--config PATH` і `--help`.

## Налаштування config.yaml

`config.yaml` містить значення, а `config.py` — dataclass-структури, безпечне
читання через `yaml.safe_load` та перевірки. Некоректні ключі, типи й діапазони
спричиняють зрозумілу помилку до відкриття камери. Для іншої конфігурації
скопіюйте **весь** файл, змініть значення і передайте його через `--config`.

| Секція | Що налаштовує |
|---|---|
| `paths` | Папка слайдів і розширення файлів |
| `camera` | Індекс камери, віддзеркалення, розмір медіанного фільтра, перестановка міток рук |
| `detection` | Кількість рук, пороги детекції, відстеження та визначення сторони |
| `gestures` | Час утримання, геометричні пороги, індекси точок пальців |
| `drawing` | Кольори BGR, їхні назви, товщина пензля і гумки, точки керування |
| `display` | Розміри вікон, кольори й розміри курсора, тексту, точок руки, клавіші виходу |
| `downloads` | URL початкових матеріалів і тайм-аути завантаження |

Наприклад, `window_size: [800, 600]` задає розмір обох вікон.
`median_kernel` має бути додатним непарним числом, типово 5.
`hold_seconds: 1.0` означає спрацювання **строго після** однієї секунди;
значення менше 1 не допускається відповідно до умови завдання.

`straight_cosine: -0.75` — поріг косинуса кута суглоба.
`raised_margin: 0.1`, `thumb_distance: 0.45` і `folded_margin: 0.15` —
відносні відстані від масштабу долоні. `sideways_ratio` порівнює
горизонтальне та вертикальне відхилення великого пальця.
`finger_tips: [8, 12, 16, 20]` відповідає кінчикам вказівного, середнього,
безіменного пальців та мізинця. Індекси відповідають схемі MediaPipe
і не є довільними числами; змінюйте їх лише разом із розумінням геометрії.

Чорний колір зарезервовано для прозорих ділянок полотна й гумки.
Структурні числа (наприклад, кількість каналів BGR, 21 точка MediaPipe,
нульові індекси та математичні межі координат) залишені у коді.

## Жести правої руки

| Жест | Дія |
|---|---|
| Відкрита долоня, усі пальці розправлені | Почати показ, очистити всі полотна |
| Лише вказівний угору, великий притиснутий | Наступний слайд |
| Лише великий убік | Попередній слайд |
| Вказівний і середній угору, великий притиснутий | Малювати рухом вказівного пальця |
| Вказівний і середній угору, великий убік | Червоний → зелений → синій → червоний |
| Стиснутий кулак | Стирати, переміщуючи середину долоні |

Тримайте всю праву руку перед камерою; детектор типово відстежує одну руку.
Кожен жест підтверджується утриманням понад одну секунду. Навігація, очищення
та зміна кольору виконуються один раз за утримання. Для повторення змініть
жест або приберіть руку. Малювання і стирання тривають після підтвердження.
Зміна жесту або втрата руки скидає таймер і розриває штрих.

Полотна зберігаються окремо для кожного слайда до очищення або завершення
програми. Відкрита долоня очищує їх, залишаючи поточний слайд.
На першому й останньому слайдах навігація зупиняється.

## Як працює програма

1. OpenCV читає кадр, виконує `cv2.flip`, `cv2.medianBlur` і перетворення BGR → RGB.
2. MediaPipe знаходить 21 точку руки. Власна геометрична логіка повертає `Gesture` (Enum).
3. `GestureGate` перевіряє тривалість. `handle_gesture` виконує разові команди.
4. `cv2.line` з'єднує попереднє й поточне положення пальця на чорному полотні.
5. Маска `np.any(canvas != 0, axis=2)` переносить нечорні пікселі на копію слайда.
   Гумка записує чорні лінії та відкриває оригінал.
6. OpenCV показує слайд і камеру. При виході ресурси звільняються через `finally`.

## Перевірки та типові проблеми

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Тести перевіряють конфігурацію, аргументи, усі шість жестів на синтетичних
точках, таймер, навігацію, маску, гумку, розрив штриха та завантаження зображень.
Вони не замінюють ручну перевірку живої камери: після змін покажіть усі жести.

- `No module named yaml`: установіть оновлений `requirements.txt` у вибране оточення.
- Камера недоступна: закрийте інші програми, перевірте дозвіл або спробуйте `--camera 1`.
- Жест не розпізнається: забезпечте освітлення, тримайте пальці вгору; за потреби спробуйте `--swap-hands`.
- Не знайдено слайди: перевірте шлях у YAML або передайте `--slides`.
- Якщо запускаєте на іншому комп'ютері, створіть нове оточення. Папку `.venv` не копіюйте.

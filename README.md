# 🖐️ Gesture Slides
### Керуй презентацією одним рухом руки

Застосунок на Python та OpenCV для керування презентаціями
за допомогою жестів перед вебкамерою. Перемикай слайди,
виділяй головне та малюй поверх презентації без миші й клавіатури.

## ✨ Заплановані можливості

- 🖐️ Запуск презентації та очищення полотна відкритою долонею.
- ☝️ Перемикання слайдів уперед і назад за допомогою жестів.
- ✌️ Малювання поверх слайдів двома піднятими пальцями.
- 🎨 Зміна кольору по колу: червоний → зелений → синій.
- ⏱️ Підтвердження жесту утриманням довше секунди
  для захисту від випадкових перемикань.
- 🧽 Додатково — гумка для стирання малюнків.

## 🛠️ Технології

Python · OpenCV · Розпізнавання жестів · Вебкамера
